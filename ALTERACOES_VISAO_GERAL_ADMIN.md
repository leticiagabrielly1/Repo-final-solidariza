# Visão geral administrativa

- Administradores que acessam `/painel` são direcionados para `/admin`, evitando a interface comum de doador.
- Resumo de roupas, alimentos, higiene, estoque total, produtos abaixo de 10 unidades, famílias, moradores, pedidos de cesta e doações físicas.
- Gráficos de necessidades, estoque e tipos de doação, além dos gráficos de metas e crescimento já existentes.
- Tabela com produtos e quantidades, filtrada pela unidade do administrador.
- Dados consultados diretamente no banco SQLite existente; nenhuma doação foi inventada.
- O estoque inicial permanece demonstrativo; Pix é apenas simulação.
